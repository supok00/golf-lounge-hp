# My Golf Lounge — 휴대폰 저장판 (golf-lounge-hp)

[My Golf Lounge](https://github.com/supok00/golf-lounge) v1.1과 같은 화면·기능을 쓰되, **기록을 휴대폰 안에 저장**하는 판입니다. GitHub 저장소·토큰을 쓰지 않습니다.

**설치 주소**: https://supok00.github.io/golf-lounge-hp/ (이 저장소에는 앱 코드만 있고 기록은 없습니다)

## 휴대폰에 설치 (안드로이드)

1. 휴대폰 **Chrome**으로 위 주소를 엽니다.
2. 오른쪽 위 **⋮ → 앱 설치**(또는 「홈 화면에 추가 → 설치」)를 누릅니다.
3. 앱 서랍·홈 화면에 **골프 라운지** 아이콘이 생깁니다. 이후에는 아이콘으로 엽니다(인터넷 없어도 실행).
4. 처음 열면 **「golf-lounge 웹 기록 가져오기」**로 기존 기록(라운드·기준값·사진)을 한 번 옮기거나, 백업 파일로 복원하거나, 새로 시작합니다.

> 예전에 만든 APK(사이드로드)는 갤럭시 S25+에서 Play 프로텍트가 「유해 앱」으로 막아 실행되지 않았습니다. Chrome의 「앱 설치」는 Google이 서명한 안드로이드 앱(WebAPK)을 만들어 주므로 이런 차단이 없습니다.

## 데이터 — 이 휴대폰에 저장

- 기록·기준값·사진은 앱 저장공간(IndexedDB)에 있고, 서버로 보내지 않습니다. 설치한 앱은 저장공간이 **영구 보관**으로 잡혀 휴대폰 공간이 부족해도 지워지지 않습니다.
- **앱을 지우거나 Chrome 「사이트 데이터 삭제」를 하면 기록도 지워집니다.** 설정 → 데이터 → **백업 파일 내려받기**(기록·기준값·사진 한 파일, 다운로드 폴더)를 가끔 하고, 파일은 PC·클라우드에도 옮겨 두세요. 2주 넘게 백업하지 않으면 상태줄에 「⚠ 백업 필요」가 뜹니다.
- 복원: 설정 → 데이터 → **백업 파일에서 복원**. 예전 golf-lounge의 `rounds.json`도 받습니다.
- 인터넷이 필요한 것: 처음 기록 가져오기, 앱 업데이트 받기, 사진 글자 인식(처음 한 번 인식 데이터 받기).

## 웹판(golf-lounge)과 다른 점

| | golf-lounge (웹) | golf-lounge-hp (휴대폰) |
|---|---|---|
| 기록 위치 | GitHub 저장소 `data/` | 이 휴대폰 앱 저장공간 |
| 저장에 필요한 것 | GitHub 토큰 | 없음 |
| 여러 기기에서 보기 | 됨 | 안 됨(이 휴대폰만) — 옮길 때는 백업 파일 |
| 인터넷 없이 | 마지막으로 받은 기록 보기 | 입력·저장·분석 모두 |
| 설정 화면 | GitHub 연결 | 데이터(백업·복원·가져오기·지우기) |

## 코드

- `js/localstore.js`: 휴대폰 저장소(IndexedDB). 화면 코드가 그대로 쓰도록 golf-lounge의 저장소 함수와 같은 이름(`GitHubStore.load/update/putFile…`)을 씁니다.
- `js/vendor/chart.umd.min.js`: 차트 라이브러리를 앱 안에 두어 인터넷 없이도 그래프가 나옵니다.
